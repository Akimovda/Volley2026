# visual-check

Инструменты (dev, `/var/www/volley-bot/backend`), PNG кладутся в `/tmp/shots` и смотрятся через Read:

- `node tools/shot.mjs <путь> --vp 360x740,390x844,1280x800 --theme both [--app] [--full] [--measure sel] [--click sel] [--hide sel] [--cookie n=v]`
- `node tools/shot-diff.mjs before.png after.png` — доля изменённых пикселей + diff.png (размеры должны совпадать).
- `node tools/a11y.mjs <путь> --theme night` — контраст/подписи (axe-core).
- `php tools/blade-lint.php file.blade.php` — компиляция Blade + `php -l` (хук делает это сам после Edit/Write).

## Порядок
1. Если правка меняет существующий вид — СНАЧАЛА снять «до» (`--out /tmp/shots/before`), потом править, потом «после» (`--out /tmp/shots/after`) и `shot-diff`.
2. Прогнать минимум 360 и 390 px + 1280 px, `--theme both`. Для страниц, видимых в приложении, — ещё `--app`.
3. Читать вывод: `⚠ горизонтальный overflow`, `pageerror`, измерения `--measure` (высоты соседних кнопок равны? зазоры между карточками > 0?).
4. Посмотреть PNG (Read) и описать, что реально видно; не утверждать «выглядит ок» без просмотра кадра.
5. Закрытые страницы — только на dev с cookie демо-пользователя (`is_bot`, `@example.invalid`), по правилам CLAUDE.md («Тестовые данные для кадров»); на прод и реальные сессии не ходить.

## Ловушки проекта (проверять в первую очередь)
- `row row2` → карточки слипаются при переносе (ожидаемый зазор ~17–20px); использовать `row`.
- `.card {height:100%}` растягивает карточку списка → `height:auto` инлайном.
- `.form select` схлопнут в 1px без `createCustomSelect()`; `.checkbox-item` без предка `.form` — голый чекбокс; динамические select/чекбоксы нужно оборачивать.
- Тёмная тема: inline `style="color:..."` не переопределить классом; `body.dark .btn` перебивает прозрачные контурные кнопки; контурная кнопка не выше заливной (замерить `btn` vs `btn-outline` — 43/43, small 28).
- Safari: `<a href="#x">` без preventDefault, нативный smooth-scroll под липкой шапкой, flex в ячейке auto-таблицы, `height:100%` у аватара в `aspect-ratio`-контейнере — в headless Chrome НЕ воспроизводятся; такие места подсвечивать пользователю как «проверить на iOS».
- Узкие экраны: корневой шрифт флюидный (`clamp` в `html` ≤480px), всё в `rem`; в `html.is-app` свой запас под шапкой — не уменьшать.
- Blade: `@json(...)` с вложенными скобками, `@else@include` без пробела — ломаются молча; хук/`blade-lint` это ловит.
- Белые тексты на акцентном оранжевом `#e7612f` дают контраст 3.41 (axe, известно) — не считать новой регрессией.
- Скрипты на dev шлют алерты в GlitchTip: любые вспомогательные `php`-скрипты запускать с `SENTRY_LARAVEL_DSN=`.
